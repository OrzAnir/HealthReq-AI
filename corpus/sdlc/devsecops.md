# DevSecOps

DevSecOps combines development, security and operations. Security checks (static analysis, dependency scanning, secret scanning, security tests) and automated testing run inside a continuous integration and continuous delivery (CI/CD) pipeline, so every change is built, tested, scanned and can be deployed quickly.

Strengths: frequent, reliable releases; security is built in rather than added at the end; fast detection and fixing of vulnerabilities; strong audit trail of every change.

Weaknesses: needs automation, tooling and operations skills; cultural change for teams; continuous deployment may conflict with formal release approval in regulated settings unless approval gates are added to the pipeline.

Choose DevSecOps when the system handles sensitive data, must be updated frequently and securely, and runs as an online service. It is often combined with Agile.

Source: SDLC reference notes written for this project, summarising standard software engineering textbook material (Sommerville; Pressman).
